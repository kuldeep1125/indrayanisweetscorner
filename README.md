# Indrayani Sweet Corner (इंद्रायणी स्वीट कॉर्नर)

> **Handcrafted Royal Mithai, Festive Gifting & Authentic Maharashtrian Breakfast**  
> Landmark Sweet Corner located in Sector 3, S-Block, MIDC Bhosari, Pimpri-Chinchwad, Pune.

---

## 🏛️ About The Brand

**Indrayani Sweet Corner** is a premier sweet shop and breakfast landmark serving the industrial community of MIDC Bhosari and residents of Pimpri-Chinchwad, Maharashtra. Renowned for pure cow ghee mithai, seasonal delicacies (Royal Ghewar, Ukadiche Modak), handcrafted dry fruit hampers, and morning breakfast (Kanda Poha, Samosa, Jalebi).

---

## ✨ Features & Architecture

- **Vertical Slider Experience (`/`):** Luxury full-screen vertical storytelling showcase preserving traditional halwai artistry.
- **Digital Artisanal Menu (`/menu`):** Dynamic category filtering (Mithai, Festive Specials, Breakfast, Savories) with authentic photography, regional naming in Marathi, pure ghee indicators, and instant WhatsApp ordering.
- **Custom Hamper & Gifting Concierge (`/custom-box`):** Curated gift boxes for Diwali, weddings, and MIDC corporate orders with a real-time hamper builder and lookbook.
- **Heritage & Storytelling (`/story`):** The journey of artisanal halwai craft, pure cow ghee standards, and early-morning kitchen traditions.
- **Verified Customer Reviews & Direct Feedback (`/reviews`):** 1-click automated Google Review launcher with unique review generation, star ratings, and community testimonials.
- **Interactive Contact & Directory Hub (`/contact`):** Store GPS coordinates, operational timings, inquiry submission via WhatsApp, and direct links to all verified online platforms.

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, Server Components & Static Site Generation)
- **Language:** TypeScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) with royal Indian theme palette (Maroon, Saffron, Gold, Ivory)
- **Motion & Interactions:** [Framer Motion](https://www.framer.com/motion/) & [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Icons:** [Lucide React](https://lucide.dev/) & accessible custom brand SVGs
- **SEO & Structured Data:** JSON-LD Schema markup for LocalBusiness, Open Graph, dynamic sitemap (`/sitemap.xml`), and `robots.txt`

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17+ or Node.js 20+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/kuldeep1125/indrayanisweetscorner.git
cd indrayanisweetscorner

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Run linting
npm run lint

# Compile optimized production build
npm run build

# Start production server
npm run start
```
